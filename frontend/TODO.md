# Web interface follow-up

The integrated interface supports catalogue, account, seller and administrator journeys. [Testing](../docs/TESTING.md) records the verified behavior; the earlier phase-by-phase tracker is retained in [historical planning](../docs/archive/frontend-planning.md).

## Remaining work

- Maintainers connect approved terms/privacy content through the server-side policy URLs.
- Contributors verify account and media flows against isolated real Auth/Storage services and the intended TLS/proxy host.
- Contributors validate reviewed bilingual legacy content and monetary metadata after the approved data workflow.
- Maintainers arrange a compatible shared preview host with safe demonstration services.

Map view, direct WhatsApp contact, settings and administrative reporting remain disabled in the feature configuration. Future work on these areas requires defined requirements and service support before the interface advertises it.

The shared [remaining-work list](../TODO.md) covers database adoption, recovery, operations and release gates.
