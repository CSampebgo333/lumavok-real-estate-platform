# Maintained integration status

The earlier mock-to-backend proposal is superseded by the implemented [architecture](ARCHITECTURE.md), [API contracts](API_CONTRACT.md), [integration report](INTEGRATION.md) and [deployment gates](DEPLOYMENT.md). The original repository retains the historical version. Do not follow old instructions to introduce a second JWT authority, anonymous server favorites or unbounded dashboard endpoints.

Current remaining integration work concerns operator staging validation, verified legacy identity/content mapping, managed provider behavior and recovery rehearsal. These are listed explicitly in the current reports; source implementation is not evidence of a production deployment.
