# Source history and attribution

The integrated application was consolidated from reviewed commit `29a70cf2202d1831593b008fd91ce998be6c83da` in [the original repository](https://github.com/adoumouangnamouemmanuel/real-estate-platform). The original repository and every shared branch are retained.

`branch-inventory.json` pins every inspected branch. Generated dependency files and machine-local files are counted separately where excluded from first-party review.

The original database diagram describes the earlier schema. It remains [in the original dba branch](https://github.com/adoumouangnamouemmanuel/real-estate-platform/blob/cd80160779dcd2bdcebee1e12692d695e7380d42/database/full-database-design/docs/DB_ER_DIAGRAM.pdf); this repository documents the current schema in text so it can evolve with migrations.

The five original Burkina Faso seed files are preserved byte-for-byte, with SHA-256 preservation tests. No production records, private backup, credentials, or rollout manifest are included.

The inherited confidential roadmap and handoff are excluded from public consolidation. The original repository retains them; the current architecture, setup and API guides describe the integrated implementation.
