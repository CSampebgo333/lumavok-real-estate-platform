# Historical records

These files preserve earlier development and verification records. Their original prose, commands, counts, paths and limitations belong to the versions they describe. They are not current setup instructions, active requirements or evidence that production was deployed.

| Record | Scope |
| --- | --- |
| [Frontend planning](frontend-planning.md) | Original phase-by-phase frontend tracker |
| [Frontend changelog](frontend-changelog.md) | Earlier frontend implementation history |
| [Testing history](testing-history.md) | Consolidation checks and intermediate verification attempts |
| [Operations history](operations-history.md) | Recorded repository protection, migration recovery and service-access checks |

The records are preserved unchanged. Their old relative references may describe historical repository locations. Current commands and responsibilities are maintained in the [documentation index](../README.md), [Testing](../TESTING.md) and [Deployment](../DEPLOYMENT.md).
